# Preserved inspiration

`ridge-stream-reference.fragment.html` is the original inline study, copied intact before building the app. `ridge-stream-reference.html` wraps it as a standalone HTML document for viewing. It includes the running, maths and coffee artefacts that were deliberately left out of v1.

The production app does not import either file. Its layout keeps the typography, tag colours, centred primary media, collapsed transcript and day headings while removing generated views.

The reference contains synthetic/example posts and media. It is not a record of ridge’s actual life. Its Codex state hooks belong to the original study; the real app uses SQLite and its own server APIs.
