# Example content

These files are used only by `npm run demo`, which writes to `.local/demo` rather than your real `data/` directory.

- `coffee.jpg`: the Chemex sample photograph from the [Gatsby Netlify CMS starter](https://github.com/netlify-templates/gatsby-starter-netlify-cms), distributed with that starter. It is a design placeholder, not ridge’s own photograph.
- `reflection.m4a`: a synthetic sample voice note created for the interaction study, not a recording of ridge.

The sample recipe, runs and other entries are illustrative. Normal startup begins with an empty database.
